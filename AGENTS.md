# Agent Instructions

* Project: Chrome extension that simplifies Google Search and reduces unnecessary loading.
* The main goal is to reduce unnecessary network requests, processing, and AI-related features for a lighter, faster, and more environmentally conscious Google Search experience.
* Performance and reduced resource usage should be prioritized when choosing an implementation.
* Prefer preventing unnecessary content or requests from loading rather than simply hiding them after loading.
* Modify existing Google elements whenever possible instead of recreating them.
* Preserve native links, behavior, and selected states.
* Inspect and reuse existing project code before adding new code.
* Make targeted changes only. Avoid unrelated refactoring and unnecessary dependencies.
* Keep the extension lightweight and robust against minor Google DOM changes.
* Do not create or update README files unless explicitly requested.
