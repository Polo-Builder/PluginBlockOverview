Google sans AI Overview

Les liens Web, dans l’interface habituelle de Google.

Activé, le plugin demande les résultats Web. Désactivé, il ne redirige plus les recherches.

Onglets : Tous, Actualités, Images, Vidéos, Maps. Désactivé : les onglets d’origine réapparaissent.

Tous ouvre les résultats habituels de Google, qui peuvent inclure un Knowledge Panel et des AI Overviews.

Limiter les chargements évitables

Quand le plugin est actif, force les résultats Web et désactive le préchargement des pages dans tout Chrome. Certaines pages pourront s’ouvrir moins vite. Réglage réversible.

Options Google à vérifier manuellement

Dans Search Labs, désactivez les expériences génératives auxquelles vous participez, si cette option existe pour votre compte.

Dans les paramètres Google, désactivez les aperçus vidéo automatiques si le réglage est proposé. Il n’est pas disponible partout.

Ces options ne sont pas modifiées par l’extension. La personnalisation est conservée, faute de bénéfice établi.

Le mode Web demande des résultats sans AI Overview. Il ne contrôle pas les calculs des serveurs Google ni toute utilisation d’IA. Aucune économie d’énergie mesurée.
